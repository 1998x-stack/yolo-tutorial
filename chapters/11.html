TRAINING DATA ／ CHAPTER 11

数据增强：变换图像时，标注也必须改变

检测数据增强不是滤镜集合，而是图像、边界框、类别和样本来源同步变换的坐标系统。用裁剪、Mosaic、MixUp 与 Copy-Paste 的具体例子建立可审计训练流水线。

1. 训练样本由图像和标注共同组成

分类任务把一张图像对应一个标签；目标检测却要求每张图像对应一组 `(class_id, x_1, y_1, x_2, y_2)` 框。因此对图像做随机缩放、翻转、裁剪、拼接，必须对每个框做一致的几何变换。否则模型看到的是经过改变的物体，收到的却是旧图像的坐标，损失函数就会把错误位置当成监督。

我们从一张 640×480 的图片和像素框 A=(120,80,280,240) 出发。若水平翻转后宽仍为 640，A 的新框是 (360,80,520,240)；如果只翻转图而不改框，标签偏移达数百像素。对于裁剪，框既要平移，又要裁掉落在新画布之外的区域。

2. 翻转与裁剪：先推导映射，再写代码

框坐标采用连续像素边界约定 `x_1<x_2, y_1<y_2`；水平翻转宽度为 W 的图像时，新坐标为 (W−x₂, y₁, W−x₁, y₂)。若保留窗口 (l,t,r,b)，新框的局部坐标通过 与裁剪区域取交集 → 减去左上角偏移 得到。特别要在裁剪后决定保留标准：某个物体只剩一条窄边时可以按可见面积比例过滤，但应明确所用阈值。

[x1′,x2′]=[W−x2,W−x1]

裁剪区间 [l,r]×[t,b] 与框 A 的可见面积定义为 max(0,min(x₂,r)−max(x₁,l)) × max(0,min(y₂,b)−max(y₁,t))。选择阈值 `visible_area / original_area ≥ τ` 时，τ 的含义是保留下来的像素面积比例，不是 IoU。若图像还经历 resize 或 letterbox，应在像素/归一化坐标之间显式转换。

# 只审计框坐标，不需要安装 OpenCV 或 PyTorch
python -m labs.augmentation_geometry
# flip_horizontal((120,80,280,240), width=640) -> (360,80,520,240)
# crop_xyxy((100,50,340,290), crop=(150,70,320,280), min_visible=0.2)
# -> (0,0,170,210)（教学示例，像素坐标）

可运行的几何校验脚本 会检查边界、非正尺寸与可见比例，但不会真的加载像素。它是增强管线的一道“标签单元测试”，不是可替代训练框架的完整增强器。

3. Mosaic：四块图像共享一张训练画布

YOLOv4 所用 Mosaic 技术从四张图片中取区域组成一张训练图像。假设目标画布为 640×640，拼接交点在 `(c_x,c_y)`，四个区域分别是左上、右上、左下、右下。每个来源图的坐标先按该区域的缩放和平移关系映射，再裁剪到有效区域；不允许仅将四个标注文件直接拼接。

这样合成使一个 batch 中遇到的目标尺度、背景和空间组合更加丰富。代价是边缘目标更容易被截断，且强拼接可能生成与真实数据分布差异很大的场景。用于视频或医学影像时，还需要审查不同来源混合的合理性和数据泄漏风险。

4. MixUp、CutMix、Copy-Paste：三种看似相近的混合

MixUp 将两张图像做全图线性叠加，系数 `λ∈[0,1]`；论文首先面向分类提出。检测框集合可以在混合后保留来自两幅图的目标，并根据实现定义对象权重，但并不存在所有检测器通用的“把两个框坐标按 λ 求平均”规则。CutMix 将第二图的一块矩形区域贴到第一图的相应位置；原始 CutMix 论文同样首先提出分类训练，目标检测实现必须补充遮挡与裁剪标签逻辑。

Imix=λIA+(1−λ)IB

Copy-Paste 常见于拥有实例掩码的分割数据：从另一幅图抠出一个实例及其 mask，放到新背景中并重新计算框与遮挡。仅有外接矩形时，直接复制整个矩形会把源背景也一并复制；它不是论文所说的实例掩码级 Copy-Paste。原始 Simple Copy-Paste 论文研究的是实例分割场景，不应把其 mask AP 改进无条件外推到通用 YOLO 检测。

增强方法图像变换检测标签注意事项
MixUp像素线性混合保留两组目标；权重定义与损失实现匹配
CutMix矩形块替换判断目标被遮挡/切断的可见比例
Copy-Paste以 mask 贴入目标实例处理遮挡、实例 ID、框重新计算
Mosaic四区域拼接四套几何映射，统一坐标与过滤规则

5. SAT 与“训练时变换”有何不同

YOLOv4 提到 Self-Adversarial Training（SAT）：在训练流程中利用模型信息构造对当前模型更具挑战性的输入，再用相应监督训练；与随机翻转的区别在于增强依赖模型响应，而不只是从固定分布抽样一个变换。在通用介绍中容易把 SAT 混为 FGSM 式独立对抗攻击，或者声称所有 YOLO 版本默认开启，这两种说法都不准确。具体步骤、损失及是否启用应与 YOLOv4 所固定的 Darknet 源码对应。

对于一般检测项目，先处理可测量的几何与颜色增强，再评估更复杂的模型相关增强。强化训练不等于提升部署时的物理对抗鲁棒性，后者需要专门威胁模型、攻击范围与测评集。

6. 用消融实验决定增强管线，而不是复制配方

建议建立四个版本：① 无几何变换的基线；② 翻转/缩放/裁剪；③ 加入 Mosaic；④ 额外加入 MixUp 或 Copy-Paste。固定数据划分、模型架构、初始化、训练步数与输入尺寸，比较同口径的 COCO AP、AP50、AP75、各目标面积 AP、不同拍摄域上的误检率。避免在验证集反复试验后用同一份数据宣称“最终测试精度”。

正式训练前，随机抽取每种增强后的图像并把标签覆盖绘制，至少检查：框与目标是否重合、裁剪后是否有负尺寸、无目标图是否被误标、相机/视频片段是否跨训练与测试混用。不同实现对退化框过滤、混合标签、概率与关闭强增强的训练阶段有不同约定，需要随配置一起归档。
