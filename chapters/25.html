EVAL / DIAGNOSIS ／ CHAPTER 25

模型评估与调优：指标、错误分解与阈值

一个 mAP 数字不足以说明模型的强弱。评估的任务是把错误拆开，找到可操作的瓶颈，再用受控实验验证改动。

1. 指标从哪里来：匹配、统计量与 AP

检测评估的第一步是匹配：把预测框与真实框按类别和位置对应起来。常用的判据是交并比（IoU）超过阈值且类别一致。匹上的是真正例 TP；没匹上的预测是假正例 FP（误报或定位差）；没被匹上的真实框是假负例 FN（漏检）。检测基本不用真负例 TN，因为背景“正确不报”的数量难以有意义地统计。

由这三个量得到精确率与召回率：P=TPTP+FP，R=TPTP+FN。两者此消彼长：提高置信度阈值会减少 FP、提高 P，同时把一部分真目标挡掉、降低 R。

把预测按置信度从高到低排序，逐条累加 TP/FP 就能得到一条 PR 曲线。AP 是这条曲线下的面积：

AP=∫01p(r)dr

mAP 是各类别 AP 的平均（或按不同口径聚合）。这里必须区分两个常被混用的指标：AP@0.5 只在 IoU=0.5 一个阈值下计算，侧重“是否检测到”；COCO AP（记作 AP@0.50:0.95 或 mAP50-95） 在 IoU 从 0.50 到 0.95、步长 0.05 的十个阈值上平均，对定位精度敏感。两者数值不可直接比较：同一个模型通常 AP@0.5 明显高于 COCO AP。

COCO 还按目标面积分组报告 AP_s（面积 < 32²）、AP_m、AP_l，面积取自原始标注。报告时必须写清是哪个指标、哪个数据划分与哪个 IoU 口径。

2. 平均值会骗人：分项与混淆矩阵

mAP 是各类别的聚合，它可以把“某一类很好、某一类很差”平均成一个看起来不错的数字。因此第一层拆解是按类别看 AP，第二层是按目标尺度看 AP_s/m/l，第三层是看混淆矩阵。

混淆矩阵的行是真实类别、列是预测类别（或相反，取决于实现），额外增加一列/行表示背景。对角线是正确分类，非对角线是类间混淆：某两类的格子很大，说明模型分不开它们。背景列（背景被预测成目标）对应误报，背景行（目标被忽略）对应漏检。Ultralytics 风格的工具可在验证时输出混淆矩阵与 PR 曲线图，具体文件名与开关以所用版本文档为准。

现象可能原因可验证的改动
某类 AP 远低于均值该类样本少、尺度特殊或标注不一致补充该类数据与困难样本，先查该类标注一致性
A 类与 B 类互相混淆类别语义或标注边界不清晰重审这两类的标注规范，再考虑增加区分性数据
背景列很大（误报多）负样本不足或阈值偏低增加含复杂背景的负样本；在验证集上重新选阈值
背景行很大（漏检多）阈值过高、小目标特征不足降阈值并看代价；检查输入分辨率与高层特征

注意：这张表给出的是“可验证的方向”，不是保证有效的处方。任何改动都应在同一验证划分上用受控对比确认，而不是根据直觉叠加多项修改。

3. 选工作点：阈值是业务决策而非默认值

同一个模型在不同置信度阈值下处于 PR 曲线上不同的点。A 点靠近右上角，是某种折中；提高阈值向右上移动（高精度），降低阈值向右下移动（高召回）。选哪个点取决于两类错误的相对代价：安防场景漏检代价高，会偏向高召回；质检场景误报代价高，会偏向高精度。一个常用的单一指标是二者的调和平均：

F1=2·P·RP+R

除了置信度阈值，NMS 的 IoU 阈值、以及每张图的最大检测数也会改变工作点：IoU 阈值越低，重叠框抑制得越狠，可能减少重复检测但同时误删密集目标。这些参数必须与评估口径一起记录。

4. 错误分解：把 mAP 缺口拆成可修的问题

整体 mAP 不达标时，下一步是把错误按类型分解，而不是直接调参。常用的四类分解：

  • 定位误差：匹上了正确类别，但 IoU 在低阀值区间，说明“找到了但框不准”，与回归目标、输入分辨率相关。
  • 分类误差：位置对而类别错，与类别语义、标注一致性相关。
  • 背景误检：在背景区域产生框，与负样本、阈值、以及相似纹理相关。
  • 重复检测：同一目标被多个框覆盖，与 NMS 参数、密集场景相关。

四类错误的“修法”完全不同，因此必须先用固定口径统计它们的比例，再去动模型或数据。COCO 风格的错误分析还会按“被更简单/更难预测的类别干扰”等因素进一步细分，这里不展开，只需要记住：先分解，后改动。

另一个实用维度是按样本分组：目标密度、尺度、遮挡程度、光照条件。把这些属性与错误率交叉，往往能发现“垂类场景整体差”这种被平均值掩盖的模式。分组时的划分阈值应事先确定并写入报告，而不是看到结果后回头挑选分组。

5. 调优的实验纪律

调优与评估共用同一个验证划分。三条基本纪律：单一变量（一次只改一类因素，否则无法归因）、固定预算（对比实验的 epoch、增强、输入尺寸必须一致）、隔离测试集（所有决策在验证集上做，测试集只在最后用一次，否则会隐式过拟合）。

超参数搜索的方式有网格、随机和贝叶斯等，但它们的共同成本是“每次试验都要完整训练”。因此在搜参数之前应先固定结构、数据与增强这类影响更大的因素；把有限预算花在对结果影响最大的变量上。任何“某组超参更好”的结论都必须带有基准与完整配置。

最后，调优的产物不只是权重，还包括一份可回放的记录：指标口径、数据划分、改动历史以及每步的对比。评估的目的不是把一个数字抬高，而是理解模型在哪里失败、为什么失败。
