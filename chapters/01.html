FOUNDATIONS ／ CHAPTER 01

目标检测：让模型回答“是什么、在哪里”

目标检测把图像内容转化为一组可计算的目标实例：每个实例都有类别、位置和置信度。理解输出契约与评估协议，是正确阅读 YOLO 架构和实验结果的起点。

1. 一张图像，需要回答三个问题

给定一张街景图像，计算机视觉系统至少可能承担三种不同任务：判断整张图像属于什么类别、找出每个目标的位置，或者为每个像素分配语义标签。它们共享图像特征，却要求模型输出不同粒度的信息。

任务模型要回答什么典型输出空间粒度
图像分类整张图最可能是什么？类别及其概率整图
目标检测有哪些目标？每个在哪里？多个边界框、类别、置信度实例级矩形框
语义分割每个像素属于什么语义类别？像素类别图像素级，不区分同类实例
实例分割每个目标的精确轮廓是什么？每个实例的掩膜与类别像素级，并区分实例

一个检测结果通常写成 (x_min, y_min, x_max, y_max, class, score)。坐标表示矩形框左上角和右下角，类别说明目标是什么，置信度用于排序和阈值筛选。实际项目还要明确坐标是否归一化、是否采用中心点宽高格式，以及坐标对应原图还是缩放后的输入图。

2. 边界框有多准确：IoU

检测器给出一个预测框，标注数据提供一个真实框。仅仅判断二者是否相交不够：一个只覆盖目标一小角的框也可能相交。交并比（Intersection over Union，IoU）用交集面积占并集面积的比例衡量重叠程度：

IoU=A∩BA∪B

IoU 的范围为 0 到 1。0 表示没有重叠，1 表示两个框完全重合。评估时通常设定匹配阈值，例如 IoU≥0.5；但“匹配成功”还取决于类别是否正确、预测置信度排序，以及一个真实目标是否已经被更高分预测匹配。

def box_iou(a, b):
    # a、b 均为 (x1, y1, x2, y2)，坐标采用同一尺度
    ax1, ay1, ax2, ay2 = a
    bx1, by1, bx2, by2 = b

    iw = max(0.0, min(ax2, bx2) - max(ax1, bx1))
    ih = max(0.0, min(ay2, by2) - max(ay1, by1))
    intersection = iw * ih

    area_a = max(0.0, ax2 - ax1) * max(0.0, ay2 - ay1)
    area_b = max(0.0, bx2 - bx1) * max(0.0, by2 - by1)
    union = area_a + area_b - intersection
    return intersection / union if union > 0 else 0.0

a = (50, 50, 150, 150)
b = (100, 100, 200, 200)
print(f"{box_iou(a, b):.3f}")  # 0.143

这个实现刻意处理了退化框：若宽或高为负，面积按 0 计算；若并集面积为 0，返回 0 而不是产生除零错误。两个框必须使用同一坐标系，否则 IoU 没有意义。

3. 从单个框到整个数据集：Precision、Recall 与 AP

目标检测不仅要框得准，还要尽量找全目标、减少误报。对某一类别和给定评估规则：

  • Precision（精确率）：所有被模型报出的检测中，有多少是真的。TPTP+FP
  • Recall（召回率）：所有真实目标中，有多少被模型找到了。TPTP+FN
  • AP（Average Precision）：按置信度从高到低扫描预测，得到 Precision–Recall 曲线，并按指定插值协议计算曲线下面积。
  • mAP：对评估类别的 AP 求平均。不同基准对 IoU 阈值和插值规则的定义可能不同。

匹配不是简单地“每个预测各找一个最近真实框”。评估器通常按类别、图像和置信度顺序进行一对一匹配：同一个真实目标不能被多个预测重复记为 TP，重复框会成为 FP。忽略区域、crowd 标注、最大检测数等规则也会影响结果，因此复现实验必须固定评估实现和配置。

指标评估口径适合回答的问题
AP@0.5IoU 阈值固定为 0.50检测框是否达到较宽松的重叠要求？
AP@0.75IoU 阈值固定为 0.75定位是否更精确？
COCO APIoU 从 0.50 到 0.95，步长 0.05，再对类别求平均模型在多种定位严格度下是否稳定？
APS / APM / APL按目标面积分组评估模型在哪种目标尺度上薄弱？
比较数字前先对齐协议。COCO 的主指标 AP 对 10 个 IoU 阈值求平均；AP50 才是 IoU=0.50 的单阈值指标。COCO 官方评估页还定义了小、中、大目标分组。把 AP@0.5 与 COCO AP 当成同一指标比较，会得出错误结论。

4. 实时性不只是 FPS

FPS 表示单位时间处理的帧数，延迟表示单个输入从进入系统到结果可用所花的时间。两者相关但不等价：批处理可以提高吞吐量，却可能增加单帧等待时间。对视频系统，至少要分别测量解码、预处理、模型前向、解码输出、NMS 和数据传输。

因此论文中的 FPS 只能在相同硬件、输入尺寸、批大小、精度模式、推理框架和计时边界下比较。Titan X 上的历史 FPS 不能直接预测现代 GPU、CPU 或边缘设备上的速度。

5. 数据集定义了模型被怎样评价

数据集类别规模标注特点常见用途
PASCAL VOC20 类经典矩形框标注；VOC 2007 常用于 AP@0.5 基准早期检测器对比与教学实验
MS COCO80 类复杂上下文、多目标与尺度分布；提供 bbox、segmentation 等标注现代通用检测器的核心基准
ImageNet DET200 类大规模检测类别；与分类数据结合时需处理标签层级差异大类别空间检测研究

数据集的类别体系、目标尺寸、遮挡程度、标注策略和训练/测试划分都不同。一个模型在 VOC 上取得高 AP，并不意味着它能在 COCO、航拍图像或工业缺陷数据上保持相同水平。评估数字必须同时附带数据集版本、split、指标和模型输入尺寸。

6. 两阶段与单阶段检测器

两阶段检测器先生成候选区域，再对候选区域分类并精修边界框。Faster R-CNN 用 Region Proposal Network（RPN）学习候选区域，减少了早期 Selective Search 的外部依赖。单阶段检测器则在密集特征位置上直接预测类别和边界框，YOLO 与 SSD 是代表性路线。

维度两阶段路线单阶段路线
计算流程候选区域 → RoI 特征 → 分类与回归共享特征 → 密集预测 → 后处理
设计重点候选区域质量与区域级精修密集样本分配、类别不平衡与高效解码
工程权衡模块较多，便于区域级精修结构通常更直接，适合低延迟部署

这不是“准确与速度”的绝对二分。现代单阶段检测器可以达到很高精度，两阶段检测器也有高速实现；最终表现取决于骨干网络、特征融合、样本分配、训练数据和推理实现。
