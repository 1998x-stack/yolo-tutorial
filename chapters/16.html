ARCHITECTURE / DISTRIBUTION FOCAL LOSS ／ CHAPTER 16

YOLOv8：Anchor-Free、C2f 与分布式边界回归

从 640×640 输入的预测格点出发，追踪 C2f 的特征路径、解耦检测头、DFL 的离散概率与训练期的标签分配；不把教学示意当成官方消融。

1. 问题：移除预设框，是否就不需要格点？

目标检测既需要判断有什么物体，也需要定位其边界在哪里。经典 YOLOv5 v7.0 为每个尺度的每个格点预设多组宽高不同的锚框；YOLOv8 的检测头不再依赖这些预先聚类的宽高，而是用特征图位置作为预测参考点，回归到矩形四条边的距离。这里的 anchor-free 指不使用预设宽高模板，不是没有格点中心或参照坐标。

以 640×640 输入、stride = 8/16/32 的三尺度示例为例，格点总数为 80²+40²+20²=8400。一个格点可以输出多类别分数以及 4 组距离概率。8400 是原始位置数量，不是最终的检测框数量，也不保证每个位置对应真实物体。

N=802+402+202=8400

2. C2f 与解耦头：特征如何走向预测

在 C2f 中，首个卷积把输入特征投影为两部分，一部分提供旁路，一部分依次经过若干 Bottleneck；各级中间结果再沿通道维拼接，由最后一个卷积融合。重复次数 n 决定中间变换深度，因此不能把“C2f 一定更快、一定提高 2 AP”当成无条件真理：参数量、算子实现与设备都会影响延迟。

检测头通常将分类与边框分成不同卷积分支。分类预测类别分数，边框分支为左、上、右、下四个距离各给出一组离散分布。以 YOLOv8 的常见 reg_max=16 为例，回归分支每个格点有 4×16=64 个原始 logits；这不是“16 个锚框”。

3. DFL：概率分布怎样得到连续坐标？

给一条边的离散位置 0、1、…、15 分别预测 logits，经 softmax 得到概率 p₀…p₁₅；推理时按每个位置的序号加权求和，得到期望距离 d=∑i·pᵢ。在训练时，目标距离 t 落在相邻整数 k 与 k+1 之间，可使用系数 (k+1−t) 与 (t−k) 对相邻类别的交叉熵加权；这个设计让距离学习保留了分布信息。

例如真实距离 t=3.7：落在第 3 与第 4 个 bin 之间，监督权重为 0.3 与 0.7。这些是目标标签权重，不是神经网络已经预测出了 0.3/0.7 的概率。另外，DFL 不能被理解成自然地为所有遮挡提供可靠置信区间；softmax 的离散分布首先是训练与解码的表示方式。

调节目标距离 t（0–14.9），观察两相邻整数的权重如何连续变化。只演示 DFL 标签插值，不训练模型。

4. 标签分配发生在训练期，不是推理层

所谓正样本分配，是确定哪些特征点负责学习一个标注框。YOLOv8 使用的 Task-Aligned Assigner 综合分类匹配程度与 IoU 等因素，从候选中选择训练正例；并非简化为“中心区域所有点永远都算正例”。真实规则还涉及候选限制、冲突解决、超参数与实现版本。

训练目标通常由分类监督、框的 IoU 类损失与 DFL 构成。分配器在训练中使用标注数据；部署时输入只有图像，没有真实框，也不运行训练分配器。预测时将距离按 stride 转为坐标，再按置信度和后处理策略筛出最终结果。

5. 多任务模型≠一套权重同时完成所有任务

Ultralytics 的 YOLOv8 软件家族支持检测、实例分割、姿态估计与分类等任务，但这不意味着任意检测 checkpoint 可以直接当作同精度的分割 checkpoint。任务的输出头、标注格式、训练目标不同；迁移学习需要明确哪些层载入、哪些层重新初始化，并对每个任务分别验证。

做架构对比时需要固定同一 COCO split、输入尺寸、模型档位、推理后端与计时口径。官方展示的 AP50:95 与 AP50 不能混用；独立训练和 benchmark 不在本页实验范围内。

# 真实工程示例：先为当前环境锁定 ultralytics 版本
python -m pip show ultralytics
# 检测 / 分割任务使用各自相应的权重，不混用任务头
yolo detect val model=yolov8n.pt data=coco8.yaml imgsz=640
# 上述命令需要本地权重与数据；不构成 COCO benchmark 复现

6. 可以带走的架构判断方法

沿着数据流逐层提问：输入分辨率决定格点总数，C2f/PAN 决定特征通路，解耦头决定任务分支，DFL 决定定位数值表示，训练分配决定监督信号，部署后处理决定最终输出。只有把这些环节分开，才能解释 YOLOv8 相比经典锚框模型的改变，而不是把一张不可比较的指标表归因于某单一模块。
